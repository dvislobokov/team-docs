Гайд для новичков

Обновлено · Даниил · 2 часа назад · 4 мин чтения

Добро пожаловать в команду. Этот документ проведёт тебя через первую неделю: доступы, локальный запуск, кодстайл и как мы релизим. Если что-то не сходится — правь прямо здесь, документация живая.

💡

Доступы к репозиториям и стендам выдаёт тимлид в первый день. Не жди — напиши в #onboarding.

Локальный запуск

Клонируй монорепу и подними зависимости одной командой:

terminal 
$ git clone git@git:team/mono.git
$ task dev:backend   # API на :8080
$ task dev:frontend  # UI на :5173

  • ✓ Поднять проект локально
  • Сделать первый PR (README-фикс — отличный старт)
