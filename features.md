Чтобы дотянуть BlockNote до уровня Confluence, вот кастомные блоки/фичи по категориям (в скобках — статус в вашем проекте):

**Уже сделано у вас**
- Callout-панели (info/warning/success/danger/note) ✅
- @-упоминания страниц ✅
- Меню вставки по `/` и `{{` ✅
- Child-page cards (галерея дочерних страниц) ✅

**Панели и структура контента**
- **Expand / Toggle** — сворачиваемые секции (аналог Confluence Expand). В BlockNote есть toggle-блоки из коробки.
- **Panel** — уже есть через ваши callout-варианты.
- **Layout / Columns** — многоколоночная раскладка (2–3 колонки). Один из самых заметных пробелов относительно Confluence.
- **Tabs** — вкладки (обсуждали: через вложенные редакторы, нетривиально).
- **Divider с заголовком**, **Table of Contents** (у вас есть правый rail, но не как вставляемый блок).

**Макросы/динамический контент (макросы Confluence)**
- **Page tree / Children display** — дерево/список дочерних страниц (у вас частично есть — ChildCards).
- **Recently updated**, **Page properties / Labels**, **Include page** (трансклюзия — вставка другой страницы).
- **Status / Badge** — цветные бейджи (To Do / In Progress / Done).
- **Date / Deadline**, **User mention** (когда будет авторизация), **Jira/issue link**.

**Медиа и вложения**
- **Attachments** — блок с прикреплёнными файлами (у вас есть `/api/upload`, можно оформить как блок-список).
- **Диаграммы** — Mermaid (легковесно, обсуждали), Excalidraw/draw.io.
- **Embed** — YouTube, Figma, ссылки-превью (unfurl), iframe.

**Данные и таблицы**
- Таблицы у BlockNote есть; для «уровня Confluence» — **сортировка/фильтры**, **формулы**, вложенный контент в ячейках.
- **Task list / чек-листы** (есть базово), **Roadmap/Timeline**, простые **charts**.

**Совместная работа (важно для паритета с Confluence)**
- **Inline-комментарии/треды** к блокам.
- **Realtime-коллаборация** (Yjs).

**Топ-5 по влиянию для достижения уровня Confluence:**
1. **Layout/Columns** (многоколоночность) — самый ощутимый структурный пробел.
2. **Expand/Toggle** — почти бесплатно, есть в BlockNote.
4. **Status-бейджи** — маленькие, но постоянно используются в вики.
5. **Mermaid-диаграммы** — лёгкая замена draw.io.

Всё это ложится на ваш подход `createReactBlockSpec` в единой схеме (`lib/editorSchema.tsx`), а поскольку контент хранится как JSON-блоки — новые блоки автоматически попадают в поиск (через `content_text` на бэке) и в историю версий.
